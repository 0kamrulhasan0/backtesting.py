| Task | Command |
|------|---------|
| Run tests | `python -m backtesting.test` |

## Test & CI Order

CI runs: **lint → coverage → build → docs → win64**

Locally, run in same order: `flake8`, `mypy`, then `python -m backtesting.test`

## Key Conventions

- **Python ≥ 3.9** required (enforced in setup.py)
- **flake8** max-line-length = 120 (setup.cfg), Ruff line-length = 100 (pyproject.toml)
- **mypy** strict-ish: `warn_unused_ignores = True`, `warn_redundant_casts = True`
- Tests run with **warnings as errors** (see `backtesting/test/__main__.py`)
- Windows multiprocessing RuntimeWarning is ignored in tests
- Version auto-generated via `setuptools_scm` → `backtesting/_version.py`

## ConstrainedBacktest (DSE / Regulated Exchanges)

`ConstrainedBacktest` enforces market constraints for exchanges like DSE:

- **Long-only**: `Strategy.sell()` raises `NotImplementedError`; use `position.close()`
- **Lot sizing**: Orders rounded to `lot_size` (default=1)
- **Circuit breakers**: Market orders clipped to ±`price_limit_pct` (default 10%)
- **Settlement delay**: Cash held for `settlement_days` bars (default 2 for T+2)
- **Commission**: Default 0.05% per trade

```python
from backtesting import ConstrainedBacktest, Strategy

bt = ConstrainedBacktest(data, Strategy, cash=1_000_000, lot_size=1)
# Or with data source:
bt = ConstrainedBacktest.from_data_source('TICKER', Strategy, period='5y', data_source=dsebd)
```

## Notable Quirks

- **Multiprocessing**: On Linux with `spawn` start method (or Windows), `backtesting.Pool` falls back to thread pool with warning. For true multiprocessing: `backtesting.Pool = multiprocessing.Pool` and guard `bt.optimize()` with `if __name__ == '__main__':`
- **Example notebooks** in `doc/examples/` must match `.py` files (checked by `doc/build.sh` via `jupytext`)
- License: **AGPL-3.0**
- Test suite is `backtesting.test` (set in setup.py `test_suite`)
